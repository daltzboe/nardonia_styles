# Nardonia Styles

A luxury hairstylist portfolio and appointment-request website built with Next.js, TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current preview

- Responsive luxury black, champagne-gold, and warm-cream design
- Brand story, service menu, lookbook gallery, appointment request form, and payment information
- Appointment form is currently a frontend preview only. It does not save or send requests yet.
- Zelle and Cash App details are intentionally placeholders until the stylist supplies the correct payment handles.
